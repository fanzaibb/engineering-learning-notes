# 八週課綱與驗收

版本 1.1，2026-11-09。日期與時數以 [課程基準](README.md) 為準，W1 含已完成的 Day 01～03。Agent協作專項訓練共6小時，分布於各週既有後端時數。

## W1｜校準起點、資料庫持久化、身分治理

日期 11/05–11/11。後端 15 小時、Azure 9 小時、評量 2 小時、緩衝 4 小時。

**後端**

- 兩小時診斷包含一次現有端點需求變更、一次 Azure 情境說明與驗證。全數計入本週評量2小時，後端和Azure時數分開計帳。評量依提示程度與證據，不重測 JavaScript 基本操作。SQL 尚未實作，直接作為待教。
- 啟動本機 PostgreSQL，認識映像、容器、資料卷、資料庫服務、資料庫與連線。由後端執行查詢，確認連線參數與錯誤。
- 建立使用者與記帳表，學習主鍵、外鍵、型別、空值與約束。用直接 SQL 練習新增、讀取、更新、刪除及 JOIN。
- 從記憶體移轉現有端點到持久化資料。金額轉換明定規格，先用整數分，不把浮點誤差帶進寫入。
- 起步種子使用者只用來驗證資料關聯，登入授權在 W3 完成。保留每個端點目前的回應行為，變動要有紀錄。
- Agent協作0.5小時。把連線任務寫成含背景、範圍與驗收的工作說明，讓agent讀專案提出方案，使用者判斷後完成首次關鍵實作。

**Azure**

- 將既有資源群組、角色查詢、子網路、NSG（Network Security Group，網路安全性群組）帶做證據移入能力矩陣。
- 補管理群組、訂閱、資源群組、標籤、鎖定、預算、Azure Policy 的使用情境。
- 練習使用者與群組、角色指派的主體／角色／作用範圍。涉及授予權限的操作依實際權限與使用者授權進行。

**驗收**

- 新增記帳後分別重啟後端和資料庫容器，仍能查到資料。資料卷用途能由結果說明。
- 實際觸發一個外鍵或金額約束錯誤，能指出檢查在哪一層。
- 能解釋並查出一個角色指派的範圍，確認刪除練習資源後的狀態。
- 11/09 校準後重新計算 W1 剩餘工作。若剩餘時數不足，把可明確切割的項目搬到 W2 並使用緩衝，保留時間差異。

## W2｜請求邊界、結構遷移與測試、儲存體

日期 11/12–11/18。後端 14 小時、Azure 10 小時、評量 2 小時、緩衝 4 小時。

**後端與整合**

- 選定一套框架，保留既有端點契約。理解路由、驗證、業務處理、資料存取的責任，依實際需要分檔。
- 以參數化查詢處理外部輸入，理解 SQL 注入與資料、指令的邊界。
- 用 migration（結構遷移）追蹤表格變更，分開 schema（結構）、seed（種子資料）與使用者資料。
- 統一請求驗證和錯誤回應。處理 204 空本文與不同成功碼，對照前端請求封裝的行為。
- 新增單筆修改端點，明定允許修改的欄位與完整／部分更新契約，作為W4版本衝突控制的延伸入口。
- 建立整合測試環境與可重建資料。新增與查回、修改與刪除、非法輸入、缺少資料各有測試。
- 以最小前端完成列表與新增，沿用熟悉的技術與基本元件。
- Agent協作0.5小時。委派有限範圍的測試或端點修改，閱讀程式差異，對照契約執行成功與失敗測試。

**Azure**

- 儲存體帳戶的冗餘、加密與網路限制。Blob 容器、存取層、版本、生命週期與軟刪除。
- 資料角色與管理角色、存取金鑰、SAS（Shared Access Signature，共用存取簽章）及儲存的存取原則。
- Azure Files 共用與身分存取、快照、軟刪除。用 AzCopy 或 Storage Explorer 完成資料傳輸。

**驗收**

- 從空資料庫重跑 migration、種子資料與整合測試，兩次可重現。測試資料與開發資料有明確邊界。
- 存取儲存體時實際驗證允許與拒絕，說明角色、金鑰或簽章是哪一條路徑。
- 還原一個已刪除或舊版本物件並確認內容，清理測試資源。

## W3｜登入、逐筆資料權限、網路

日期 11/19–11/25。後端 13 小時、Azure 11 小時、評量 2 小時、緩衝 4 小時。

**後端與整合**

- 區分 authentication（身分驗證）與 authorization（授權）。使用成熟密碼雜湊工具及一種 session（工作階段）方案。
- 登入、登出、過期狀態。若採 Cookie，處理 HttpOnly、Secure、SameSite 與必要的跨站請求偽造防護。
- 每個私人記帳查詢、修改與刪除都包含使用者範圍。辨認前端路由守衛和服務端資料授權的差異。
- 實際設定 CORS（Cross-Origin Resource Sharing，跨來源資源共享），用瀏覽器驗證，再和 Postman 或 curl 比較。
- Agent協作1小時。交付權限需求與邊界，請agent提出或實作有限修改，使用者以跨帳號測試查核結果，將決策記入專案工作規則。

**Azure**

- 複驗子網路與 NSG，補 peering（虛擬網路對等互連）、使用者自訂路由及公用位址。
- DNS（Domain Name System，網域名稱系統）、內部與公開負載平衡器、健康探測與規則。
- 私人端點、服務端點、Bastion 的用途、邊界和設定。
- 做一次實際服務監聽與跨來源連線，安排建立、測試、診斷、清理一整條流程。權限或配額阻礙時使用預備方案並記錄未完成的證據。

**驗收**

- 未登入、登入過期，以及 A 修改 B 的資料編號都被拒絕。測試涵蓋讀寫兩方向。
- 瀏覽器可正常登入和讀取自己的記帳，能解釋憑證與跨來源許可的責任。
- 網路實驗同時有允許、拒絕、端點監聽與實際請求證據，能區分路由、門禁與服務失敗。

## W4｜交易、併發與重送、運算資源

日期 11/26–12/02。後端 13 小時、Azure 11 小時、評量 2 小時、緩衝 4 小時。

**後端**

- transaction（交易）、commit（提交）、rollback（回滾）與同一條連線。用一個記帳加稽核紀錄的多步驟操作，故意使第二步失敗並觀察第一步撤銷。
- connection pool（連線池）的借還生命週期、finally 與連線洩漏。效能調校留待後續。
- 兩個分頁儲存同一筆資料，用 version（版本）條件檢查拒絕過期覆寫，前端顯示衝突。
- 一筆新增使用冪等鍵，在資料庫唯一限制與交易下處理併發重送。定義相同鍵不同內容的行為。
- Agent協作1小時。審查交易、連線借還與併發修正，以故障注入和實際重疊請求檢查主張，寫一份發現、證據及修正紀錄。

**Azure**

- 虛擬機器規格、可用區／可用性設定組、磁碟、主機端加密、移動資源及擴展集。
- 從映像、開機／解除配置、資料磁碟與短期計費理解生命週期。
- Azure Resource Manager／Bicep 範本先讀既有檔案，開始練習重建資源。

**驗收與中期決策**

- 交易失敗後資料沒有半套狀態，連線歸還。兩個真正重疊的修改與新增重送各有可重跑測試。
- 確認第一份使用者隔離與交易成果。Azure 五領域逐項盤點，後續主題都有排程。
- 記錄時數與缺口。先延後進階多代理編排和周邊前端功能，單一agent協作沿核心任務練習，再討論是否調整考期。中期評估含在本週評量兩小時內。

## W5｜容器、部署與自動化

日期 12/03–12/09。後端 12 小時、Azure 12 小時、評量 2 小時、緩衝 4 小時。

**全端與整合**

- Dockerfile 與 multi-stage build（多階段建置），固定版本，分開映像、執行設定與資料。
- 本機前後端與資料庫可重建。部署憑證從環境或秘密管理提供。
- CI（Continuous Integration，持續整合）執行測試與建置。版本化映像與部署紀錄。
- 一個能同時相容新舊版的簡單 migration 演練，說明前端快取與既有分頁會影響更新。
- Agent協作1小時。委派建置或部署變更，核對環境設定、憑證、費用與回復方案，保存建置和部署驗證證據。

**Azure**

- ACR（Azure Container Registry，Azure 容器登錄）與身分拉取映像。
- ACI（Azure Container Instances，Azure 容器執行個體）、Azure Container Apps 的建立、資源配置與擴縮。
- App Service plan、應用設定、網路、擴縮、網域與 TLS（Transport Layer Security，傳輸層安全性）、備份與部署槽。
- Bicep 範本讀取、修改、部署與重建。代表服務用實驗驗證，考綱其他細項以專項演練與情境題補齊。

**驗收**

- 依設定從映像啟動程式，新增並讀回私人記帳。重新部署後資料仍在。
- 自動化流程能擋住一個故意破壞的測試。前端錯誤、後端錯誤可定位。
- 使用範本重建一組小型 Azure 資源，確認部署狀態與清理結果。付費服務建立前確認價格與時限。

## W6｜觀測、復原與 agent 輔助排錯

日期 12/10–12/16。後端 10 小時、Azure 14 小時、評量 2 小時、緩衝 4 小時。

**後端與整合**

- 用 request ID（請求識別碼）追蹤一次操作，區分日誌、指標與追蹤，敏感資料適當遮蔽。
- 區分程序存活與接收流量的就緒檢查，演練資料庫不可用、逾時與優雅關閉。
- Agent協作1小時。提供去敏感的故障現象與日誌，讓agent提出可驗證的假設與排查順序，由使用者驗證根因與修正。區分推測、已執行檢查和成功證據。

本週後端共10小時，1小時作協作訓練，其餘9小時作觀測、復原及核心補強。產品內的模型分類功能改為結業後選修。

**Azure**

- Azure Monitor 指標、日誌、診斷設定、基本 KQL（Kusto Query Language，Kusto 查詢語言）。
- 告警、動作群組與處理規則，Insights、Network Watcher、Connection Monitor。
- Recovery Services vault、Backup vault、備份原則、還原、報告與告警。
- Site Recovery、複寫與容錯移轉的邊界及代表操作。需額外成本或配額的部分先評估，用受控短期資源完成驗證。

**驗收**

- 用請求識別碼追到失敗點，從備份還原到隔離目標並比較資料。
- 實際觸發並確認一個告警。能解釋日誌或指標的證據。
- 使用者能判斷agent的診斷是否有證據支持，並以實際請求及資料驗證修正。
- 盤點仍空白的 Azure 目標，決定最後兩週的補課與報考準備安排。

## W7｜未知情境與考綱補弱

日期 12/17–12/23。後端 8 小時、Azure 14 小時、評量 4 小時、緩衝 4 小時。

- 使用者自己完成一項新需求，例如分類月報或可篩選匯出，包含必要的資料模型、端點、前端與測試。需求由教練於開始前指定，提供驗收而非逐行實作。
- 排查一個未預告的部署或資料故障，記錄假設、查證和修正。
- 補齊考綱細項與獨立實驗，做第一次合法未見題限時綜合練習。
- 逐項分析錯誤原因，實驗重現不熟悉的設定。更新來源與術語。
- Agent協作0.5小時。新需求可拆分時，指定研究／實作／審查角色及交付物，練習交接與整合。單一agent流程尚未熟練時用此時間補審查與交接。

**驗收**

- 新需求與故障修正具可重跑證據，使用者能解釋程式與責任邊界。
- 每個 Azure 領域都有代表實驗與清理證據，未覆蓋項目明列補課。

## W8｜交付、複驗與報考決策

日期 12/24–12/30。後端 7 小時、Azure 11 小時、評量 8 小時、緩衝 4 小時。

- 從乾淨環境重建應用，跑資料結構遷移、種子資料、測試、部署和還原。
- 檢查七項全端結業門檻，進行技術說明與延後複驗。
- 第二次合法未見題限時綜合練習，分析各領域並補弱。
- 完成官方考試介面體驗、選定語言的限時閱讀，重新確認考綱、時間、報名與監考規則。
- 全端及 AZ-104 分開回報通過、待補項目與證據。考期依當時準備程度決定。
- Agent協作0.5小時。由使用者主導一次有限需求交付，展示任務、計畫、程式差異、驗證及決策。可使用AI工具，需能解釋與調整成果。限時考試練習依正式允許資源規則進行。

## 當堂備課格式

每堂開始前準備目標、前置條件、3～5 個術語、參考資料、主要操作、成功及失敗驗證、預估時間、替代方案、清理方式。每堂結束回寫 [進度](PROGRESS.md)。

環境與付費實驗在上課前核對相容性、訂閱限制、區域、總成本與清理範圍。研究者交付文件與版本，審核者確認驗證能真正證明當堂能力。
