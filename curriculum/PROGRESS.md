## 狀態定義

| 狀態 | 可以證明什麼 | 升級所需證據 |
|---|---|---|
| L0 未開始 | 尚無學習證據 | 學習與情境說明 |
| L1 看過／討論 | 曾解釋或討論 | 使用者實際完成並驗證 |
| L2 帶做完成 | 在指引下做過且有結果 | 新情境下自行選步驟、完成與解釋 |
| L3 獨立完成 | 有獨立操作與排錯證據 | 隔一段時間換情境再次驗收 |
| L4 延後複驗通過 | 有保留與遷移應用的證據 | 後續變更時再確認 |

證據另標類型，包括程式、測試、實機、規則模擬、情境問答與閱讀。L2 規則模擬不能自動變成 L2 真實連線。口頭回答用來診斷理解，實作能力需要程式或操作證據。

| connection pool／client／release | L1 | W1 連線、W4交易 | W6 逾時與優雅關閉 |
| image／container／volume | L1 | W1 PostgreSQL | W5 自己的映像與部署 |
| authentication／authorization | L1 | W3 登入與資料權限 | W5部署、W7未知情境 |
| scope／role／principal | L2 部分 | W1 Azure權限 | W2儲存資料角色、W5受控身分 |
| 任務範圍／驗收條件／差異審查／交接 | L1 | W1～W2 agent委派 | W3～W8權限、交易、部署與成果驗收 |

首次教學附全名，使用者補上自己的例子。卡住的術語回到操作證據解釋。
